# 顶部搜索入口

## 目标与结果

顶部搜索框可以选择“知识库”或“对话标题”，提交后进入相应页面显示结果。GUEST 不显示无权使用的管理搜索入口。

## 文件职责与数据流

SearchBar.tsx 使用 GET 表单提交 query，Header.tsx 根据角色显示入口。已有 Knowledge/History 页面读取 searchParams，调用按 Session userId 隔离的服务。没有新的数据库接口，也没有把全站数据拉到浏览器过滤。

## 关键代码与设计取舍

action 仅从两个固定站内路径选取，查询内容交给浏览器 URL 编码；不会把用户关键词拼成 URL 路径。复用已有搜索页面，避免重复维护结果组件。知识库与对话标题范围明确，暂不承诺聊天正文全文搜索。

## 面试重点与易错点

GET 便于刷新、复制链接；query 不是用户身份，资源归属仍从 Session 获取。隐藏 Guest 入口仅改善体验，目标页面自身继续执行权限检查。关键词会出现在地址栏，演示时避免输入密钥。

## 验证方法

选择知识库搜索已知标题；选择对话搜索已知会话名并继续会话；搜索不存在关键词检查空状态；输入中文、&、空格检查编码；Guest 不显示入口，直接访问目标页仍被限制。

## 后续改进

数据量增长后再考虑统一结果页或正文搜索，不在当前版本引入搜索引擎。
